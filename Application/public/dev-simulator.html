ระบบจำลองอุปกรณ์และสร้าง QR Code สำหรับผู้พัฒนา

ใช้สำหรับทดสอบสแกนกล้องในแอปเพื่อผูกอุปกรณ์จริงกับเซิร์ฟเวอร์

ตั้งค่าข้อมูลจำลองของอุปกรณ์
พร้อมสำหรับการสแกน
นำมือถือเปิดแอปมาสแกน QR Code นี้
ขั้นตอนการทดสอบด้วยแอปมือถือ:
  1. เปิดแอป Smart Water Farm บนโทรศัพท์มือถือ หรือ Emulator
  2. เข้าสู่ระบบด้วยบัญชีของคุณ
  3. ที่หน้าหลัก กดปุ่มเครื่องหมายบวก (+) ที่มุมขวาบน
  4. เลือกเมนู "สแกน" จากนั้นนำกล้องมือถือมาสแกน QR Code ที่แสดงอยู่บนหน้าจอนี้
  5. แอปจะอ่านข้อมูล JSON {"d":"...","c":"..."} และทำการเชื่อมต่อเพื่อผูกอุปกรณ์กับบัญชี
